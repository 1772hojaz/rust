# These are some basic rust programs 

## To run follow this example

* 1. First compile the program
        ```bash
        $ rustc 01-example.rs --out-dir Compiled_files
        $
        ```
* 2. Move to where the compiled files are and run the file
        ```bash
        $ cd Compiled_files
        $ ls
        $ example
        $ ./example
        $ Success
        ```
